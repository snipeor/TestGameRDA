# Kingdom Rampart

A mobile-friendly side scrolling tower defense prototype built with vanilla HTML5 canvas and JavaScript.

## Playing locally
1. Serve the repository with any static HTTP server (for example, `python -m http.server`).
2. Open `http://localhost:8000` on desktop or mobile. The layout is designed for 16:9 but adapts to smaller widths.

## Controls
- Tap/Click ◀ ▶ buttons (or use **A/D** or arrow keys) to move the monarch along the road.
- Tap **Build** (or press **Space**) near a build slot to create or upgrade a tower for gold.
- Tap **Repair** (or press **R**) while near a damaged tower to restore health.
- Towers automatically attack approaching enemies. Defend the keep as long as possible!
